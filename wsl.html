Linux no Windows

Instalação do WSL 2 com Ubuntu

O WSL (Windows Subsystem for Linux) permite executar o Ubuntu e ferramentas Linux diretamente no Windows, sem dual boot ou uma máquina virtual tradicional.

NotaAntes de começar

Este tutorial requer Windows 11 ou Windows 10 versão 2004 ou posterior (build 19041 ou superior). Para conferir a versão, pressione Windows + R, digite winver e pressione Enter.

1. Abrir o PowerShell como administrador

  1. Abra o menu Iniciar e procure por PowerShell.
  2. Clique com o botão direito em Windows PowerShell.
  3. Selecione Executar como administrador.
  4. Autorize a execução.

Os comandos de instalação desta página devem ser executados no PowerShell do Windows.

2. Instalar o WSL e o Ubuntu

No PowerShell, execute:

wsl --install -d Ubuntu

Esse comando habilita os componentes necessários, configura o WSL 2 e instala o Ubuntu. Ao terminar, reinicie o computador.

Para consultar previamente as distribuições disponíveis:

wsl --list --online

3. Configurar o usuário do Ubuntu

Após reiniciar, abra Ubuntu pelo menu Iniciar. Na primeira execução, crie um nome de usuário Linux quando aparecer:

Enter new UNIX username:

Use um nome simples, sem espaços ou acentos, por exemplo aluno. Depois, crie uma senha.

Dica

Ao digitar a senha no terminal Linux, nenhum caractere aparece na tela. Isso é normal. Digite a senha e pressione Enter.

4. Atualizar o Ubuntu

Os comandos a seguir devem ser executados no terminal Ubuntu:

sudo apt update
sudo apt upgrade -y

5. Instalar ferramentas básicas

sudo apt install -y build-essential git curl wget unzip

Confira algumas instalações:

git --version
curl --version

6. Confirmar o uso do WSL 2

Volte ao PowerShell do Windows e execute:

wsl --list --verbose

O resultado deverá indicar a versão 2:

NAME      STATE      VERSION
Ubuntu    Running    2

Se o Ubuntu estiver usando a versão 1:

wsl --set-version Ubuntu 2

Também é possível conferir o estado geral:

wsl --status

7. Abrir o Linux posteriormente

Abra Ubuntu pelo menu Iniciar ou execute no PowerShell:

wsl

Para iniciar diretamente na pasta pessoal do usuário Linux:

wsl ~

8. Criar uma pasta para bioinformática

No Ubuntu:

mkdir -p ~/bioinformatica
cd ~/bioinformatica
pwd

O resultado será semelhante a:

/home/aluno/bioinformatica

Para melhor desempenho das ferramentas Linux, mantenha os projetos dentro do sistema de arquivos do WSL, como em ~/bioinformatica.

9. Acessar os arquivos do Windows

A unidade C: está disponível no Ubuntu em /mnt/c:

cd /mnt/c/Users
ls

Para abrir no Explorador do Windows a pasta Linux atual:

explorer.exe .

10. Testar o ambiente

cd ~/bioinformatica
mkdir teste
cd teste
echo "WSL funcionando" > exemplo.txt
cat exemplo.txt

Solução de problemas

Se wsl --install apenas mostrar a tela de ajuda, execute no PowerShell:

wsl --list --online
wsl --install -d Ubuntu

Se o download permanecer parado em 0,0%:

wsl --install --web-download -d Ubuntu

Para atualizar ou reiniciar o ambiente WSL:

wsl --update
wsl --shutdown
Aviso

Não use wsl --unregister Ubuntu como tentativa comum de correção. Esse comando remove permanentemente os arquivos, programas e configurações da distribuição.
